## Item 3 — done, commit `33dbaa6`

**Gate.** `node test/run.mjs kitbashNamedDesigns.test.ts
kitbashRecipeMap.test.ts kitbashParts.test.ts kitbashRetrieval.test.ts` — 8
pass, 3 correctly skipped (`CALIPER_ALLOW_SPEND` unset, live-spend tests),
0 fail. `npx tsc --noEmit` clean.

**What was measured before deciding what to fix.** 62 parts, 40 designs,
rarity split confirmed 35/25/40 (matching the brief exactly; the file's own
header comment said 30/30/40 — stale against both the real table and
`test/kitbashRecipeMap.test.ts`'s own already-correct assertion, fixed as a
one-line correction). The real finding: `DESIGN_RECIPE_MAP`'s `recipe`
field is imported into its only consumer, `kitbash-district.html`, and
never read again — the only executable path, `assembleBuilding()`, picks
parts at random by socket compatibility and never consults a named recipe
at all. Measured directly across 60,000 trials: the entire **connector**
category (8 of 62 parts, ~13%) was never reached by anything executable,
because `assembleBuilding` never looks at that category.

**Fixed**: `assembleNamedDesign(designId, options, T)` (new,
`public/kitbash-assembler.js`) actually executes a design's recipe array
generically — any length, any order, not the fixed four-slot stack
`assembleBuilding` uses. Refuses loudly (named error, not a silent skip)
for an unknown design or a recipe naming a part that no longer exists —
watched red for real via a reverted-then-restored mutation. Two of the 40
designs already used `shaft-twin-atrium` (a genuinely paired structural
form), so each gained one real, different connector between shaft and
crown, closing 2 of the 8 previously-unreachable connectors with content
that has an actual structural reason to be there. `kitbash-district.html`'s
two landmark plot slots now call `assembleNamedDesign` by name instead of
random assembly, closing the "imported but unused" gap in the one place it
was ever imported.

**What is honestly still open.** 5 of 8 connector variants remain
genuinely unreferenced by any executable path — no other design has a
second volume to connect, named as an honest gap rather than forced into
an arbitrary insertion. The `kitbash-district.html` change is
syntax-checked and logic-verified but **not visually verified** — no
browser/WebGL context was available. `kitbash-district.html`'s ownership
is ambiguous (not explicitly listed in either lane's routing); edited on
the judgment that it's this lane's kitbash demo, noted in case that's
