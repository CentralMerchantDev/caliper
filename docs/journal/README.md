# Build journal

Working notes kept from the build, moved out of the repository root.

They are session-by-session records — what was tried, what broke, and why a
decision went the way it did. They are history, not documentation: where they
disagree with the code, the code is right. `README.md` at the root is the
current description of the project.

They are kept rather than deleted because several of them record the reasoning
behind constraints that are still load-bearing, and a decision whose reason has
been thrown away is one somebody re-litigates later.
