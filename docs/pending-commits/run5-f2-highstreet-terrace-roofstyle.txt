What changed. `roofStyle` (options-overridable, `r3 < 0.6 ? "mansard" :
"parapet"`) now branches real geometry: "mansard" reproduces today's exact
lower/upper roof and both dormers, byte-for-byte, so the majority case is

omits the dormers, matching bldVilla's/bldTerrace's own existing
convention that dormers are a pitched/mansard feature and would poke

roofStyle-bearing sibling in this file already does this and the first

before any code was written. `params: { roofStyle }` was added to the
return object, which this function previously omitted entirely.
