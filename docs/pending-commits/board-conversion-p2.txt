A real bug, watched red, not narrated as smooth: the first version chained
each arterial edge centre-to-centre. Every junction verification failed
with a position mismatch of exactly the junction's own footprint radius
(25.6 m) -- the straight run went straight through where the junction's
own socket actually sits. Fixed by computing each node's junction radius
BEFORE building any edge (degree has to be known first, or an edge already
built would need rebuilding once its endpoint's radius is decided --
building the same thing twice is exactly what LESSONS.md exists to name),
then trimming every edge's endpoint back to that radius. Watched green
after, same assertions.
