Fixed
-----
1. test/livePosition.test.ts's 3 timer/poll failures. Real cause: test/
   foundationRequestClasses.test.ts sets `globalThis.window = {
   devicePixelRatio: 1 }` at module top level with no addEventListener/
   removeEventListener, and never restores it. test/run.mjs imports every
   test file into ONE shared process, so this incomplete shim leaked into
   public/live-position.js's trackLiveRect (which checks `typeof window
   !== "undefined"` and calls window.addEventListener) whenever
   foundationRequestClasses.test.ts happened to run first -- a reason that
   had nothing to do with live-position.js itself. Fixed by giving the
   shim the two no-op methods a "minimal window" should actually have.

2. test/rawSourceScan.test.ts's own gate. Two parts:
   a. 3 newly-unreviewed files. Two reviewed as genuine false positives
      (catalogueValidator.test.ts's readFileSync targets JSON data, its own
      .match() calls check assertion messages, not source code;
      genCitySummaryRetired.test.ts's matches target a generated file's
      byte-equality and a spawned process's own stdout) and named with a
      real reason. The third, cullingSuiteUnblocked.test.ts, was the one
      REAL instance of the defect shape this gate exists to catch -- a raw
      regex against another test file's own quarantine annotation, which a
      COMMENT mentioning the same string verbatim would have satisfied
      without a real skip present. FIXED, not excluded: now imports the
      shared stripSourceComments helper before matching.
   b. 3 stale exclusion entries (boardRender.test.ts, cityWorld.test.ts,
      publicClaims.test.ts) -- all three files confirmed genuinely deleted
      in earlier takedown commits (git log --diff-filter=D), their
      exclusion entries simply never pruned. Removed.
